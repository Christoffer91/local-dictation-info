Pilot privacy and support

Effective 20 October 2026. Christoffer handles support personally and clears closed routine cases within 30 days.

Review the local pilot

Review ordinary local dictation with your own short, invented content. No provider account, API key or paid transcription is needed. The steps are voluntary; you can inspect settings and help without making a recording.

Prøv lokal diktering med eget, kort og oppdiktet innhold hvis du ønsker. Ingen providerkonto eller nøkkel trengs. Du kan lese innstillinger og hjelp uten å gjøre opptak.

No audio downloads

This website supplies no recordings or downloadable test files. Do not use private work, other people's speech, sensitive information or existing dictation history for a review. You do not need to send a recording to support.

Prepare a local model

  1. Open the pilot app and finish its ordinary onboarding if shown. Choose Local Whisper. The interface language and dictation language are separate choices.
  2. Open model settings, choose NB-Whisper base for a Norwegian example, and explicitly start its download. A fresh installation needs a network connection for this preparation. Wait until the app shows that the model is ready. Downloads contact Hugging Face; see the privacy page for this separate data flow.
  3. Choose Norwegian as the dictation language. For an English example, choose and download Whisper multilingual base and select English. Local Auto is unavailable in this pilot. Selecting a cloud engine is unnecessary.

Try a short recording, if you choose

  1. Open Record. If you choose to record, grant microphone permission when iOS asks. You may decline permission; the app should explain how to continue through iOS Settings. Do not grant permissions for someone else's content.
  2. Keep the app open and speak one brief invented sentence, such as «Dette er en syntetisk test.» or “This is an invented test.” Choose Stop. Background recording is unavailable in this pilot.
  3. Wait for the local result. Review the actual words and punctuation rather than assuming the example will be exact. Correct the text if needed and inspect its saved history entry. If processing fails, read the shown error and use the app's ordinary recovery steps; no cloud upload is required.
  4. Copy or Share only if you want to test them, and choose a destination you control for this invented text. Copy uses a two-minute, device-local clipboard setting; it cannot revoke text already pasted. Sharing opens the system sheet and lets you choose the recipient.
  5. Delete the invented history entry and any remaining audio when finished. Playback retention, automatic copying, keyboard sharing and background transcription are independent settings, off by default. Nothing in these instructions requires enabling them.

Optional file import

If you already have a short, supported audio file that you created or have permission to use, you can choose it through the app's ordinary Files picker and inspect the local result. No file is supplied here. Only choose nonprivate content you control; do not grant access to unrelated documents for this review.

Useful feedback

Briefly describe expected versus actual behavior, app version, device/iOS and selected language/engine. Do not send recordings, history, API keys, provider addresses or attachments. Use the Support link in the navigation; Christoffer handles requests personally.

Transcription quality can vary, including Norwegian wording. These instructions do not promise accuracy, physical background recording or support for every file source. A successful example describes that example only.
